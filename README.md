# ICE DRAGON — stud-voxel boss (LihFolk brick pipeline)

Work in progress. A procedural frost dragon in the same style and resolution class as DemonSerpent: NumPy occupancy/colour
grids, signed-distance blends, square-stud texture, meshed + rigged + rendered in headless Blender.

Build log lives in the commit history; this README is replaced by the measured one at the end.
